# MGN Pools – Website (React + TypeScript + Vite)

Production‑ready сайт компании **MGN Pools** с современным дизайном, анимациями и рабочей формой обратной связи, который разворачивается через **Vercel** и использует serverless‑функцию для отправки писем.

## Стек технологий

- React 18 + TypeScript
- Vite (сборка и dev‑сервер)
- React Router (клиентский роутинг)
- Tailwind CSS (стили и адаптивная верстка)
- Framer Motion (анимации)
- Vercel (хостинг и деплой)
- Resend (отправка писем из формы контактов через serverless‑функцию)

## Основные страницы

- Главная: общее описание услуг, CTA и логотипы компаний.
- Commercial: коммерческое обслуживание бассейнов, список услуг и блок «Why MGN Pools».
- Residential: услуги для частных клиентов.
- Renovations: карточки услуг по ремонту/реновации с локальными изображениями.
- Repair, Bid, Training, Jobs: отдельные страницы с контентом.
- Contacts: контактная информация, карта и форма обратной связи, которая отправляет письмо на указанный email.

## Как запустить проект локально

### Требования

- Node.js 18+
- npm (по умолчанию идет вместе с Node.js)

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

После запуска Vite выведет URL (обычно `http://localhost:5173`), по которому можно открыть сайт.

### Продакшен‑сборка

```bash
npm run build
```

Собранные файлы окажутся в папке `dist`.

При необходимости можно локально посмотреть продакшен‑сборку:

```bash
npm run preview
```

## Отправка писем из формы контактов

Форма на странице Contacts отправляет данные на serverless‑функцию Vercel:

- маршрут: `/api/send-email`
- файл: `api/send-email.js`
- сервис: Resend

Для работы отправки писем нужна переменная окружения:

```bash
RESEND_API_KEY=ваш_ключ_из_resend
```

### Настройка переменной в Vercel

1. Зайти в проект на vercel.com.
2. Открыть: Settings → Environment Variables.
3. Добавить:
   - Name: `RESEND_API_KEY`
   - Value: ваш реальный API‑ключ Resend.
4. Сохранить и перезапустить деплой (или дождаться следующего).

### Как сменить email получателя

Откройте `api/send-email.js` и поменяйте массив `to`:

```js
const payload = {
  from: 'MGN Pools <onboarding@resend.dev>',
  to: ['нужный_email@пример.com'], // <-- поменять здесь
  subject: `New contact form message: ${subject}`,
  text: [
    // ...
  ].join('\n'),
};
```

После следующего деплоя письма будут уходить на новый адрес.

## Деплой на Vercel

Проект настроен для деплоя через Vercel и GitHub.

### Шаги

1. Залить репозиторий на GitHub.
2. На vercel.com нажать New Project → Import Git Repository и выбрать этот репозиторий.
3. Vercel автоматически подтянет:
   - команду сборки: `npm run build`
   - выходную директорию: `dist`
   - конфигурацию из `vercel.json` (в том числе перезапись всех маршрутов на `index.html` для React Router).
4. После завершения деплоя сайт будет доступен по адресу вида `https://имя-проекта.vercel.app`.

## Привязка собственного домена (например, с 2mhost)

1. В проекте на Vercel зайти в Settings → Domains.
2. Нажать Add и ввести свой домен (например, `example.com`).
3. Vercel подскажет, какие DNS‑записи нужно создать (обычно:
   - A‑запись `@` → `76.76.21.21`
   - CNAME `www` → `имя-проекта.vercel.app`
4. Зайти в панель управления доменом (например, у 2mhost), открыть DNS / Zone Editor и создать/обновить записи по инструкции Vercel.
5. Подождать, пока обновятся DNS (обычно от нескольких минут до часа).

После этого сайт будет доступен по вашему домену и продолжит деплоиться через Vercel при каждом `git push`.

## Для заказчика / будущего разработчика

- Весь код хранится в этом репозитории (React + TypeScript).
- Любые изменения вносятся через PR или напрямую, затем делается `git push` — Vercel автоматически собирает и выкладывает новую версию.
- Если нужно:
  - изменить тексты/контент — это файлы в папке `src/pages` и компоненты в `src/components`;
  - обновить email для формы — править `api/send-email.js` (поле `to`);
  - поменять ключи и секреты — использовать раздел Environment Variables в настройках проекта Vercel.
